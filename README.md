# 💬 WhatsApp - Login & Autenticação

## 📌 Sobre o projeto
O projeto consiste em desenvolver uma interface de login inspirada no WhatsApp, permitindo o acesso por telefone e senha. O frontend se comunica com uma API para autenticar usuários e acessar mensagens.
 --- 
## 🎯 Objetivos
- 📱 **Interface Intuitiva:** Design responsivo e fiel à experiência visual do WhatsApp.
- 🔗 **Integração Full Stack:** Conectar a camada de apresentação (frontend) à regra de negócio (backend).
- 🛡️ **Segurança:** Validar credenciais de usuários cadastrados no banco de dados.
- 💬 **Acesso ao Chat:** Exibir mensagens e histórico de conversas após login bem-sucedido.

---

## 🎯 Resultado esperado
Integrar o frontend, a API e o banco de dados para permitir a autenticação de usuários e o acesso às mensagens por meio de uma interface inspirada no WhatsApp.
